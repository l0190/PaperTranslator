应用启动:
- 前端启动:npm --prefix apps/web run dev -- --hostname 0.0.0.0 --port 3000
- 后端启动:uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000 
重置密码:
``` bash
python -c "from getpass import getpass; from pwdlib import PasswordHash; 
print(PasswordHash.recommended().hash(getpass('YouDub password: ')))"
```
